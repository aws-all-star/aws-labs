
## Requirements
1. 선택한 데이터와 선택한 데이터베이스 서버를 사용하여 간단한 데이터를 저장하는 데이터베이스를 만듭니다.
   예를 들어 2024년도 KBL 등록된 투수 선수 중에 그들의 ERA(평균 자책점), G(경기 수) 및 W(승리 수) 등에 대한 데이터가 있는 첨부된 KBL 데이터를 사용할 수 있습니다.
   https://www.koreabaseball.com/Record/Player/PitcherBasic/Basic1.aspx
   
2. 데이터를 저장하는 데 사용할 수 있는 데이터베이스의 몇 가지 예로는 MySQL, PostgreSQL, MongoDB 등이 있습니다.
   원하는 프로그래밍 언어와 프레임워크로 API 서버를 만드세요. 몇 가지 예:
   2.1. Fast API
   2.2. Node + Express
   2.3. Java Springboot

3. 사용자가 API 마이크로서비스를 통해 데이터베이스에서 데이터를 검색할 수 있도록 API 서버에 몇 개의 GET 엔드포인트를 만듭니다. 엔드포인트의 몇 가지 예

/Players: 예를 들어 쿼리를 통해 데이터에서 처음 10명의 플레이어를 반환합니다. SELECT Player Name FROM nhl LIMIT 10

/Toronto: 토론토 메이플 리프스의 모든 선수를 반환합니다. 예를 들어 쿼리를 통해 선수 이름을 선택하십시오. Nhl WHERE 팀 = 'TOR' Linux OS에 대한 정보

/Points: 점수에서 상위 10명의 플레이어를 반환합니다. 예를 들어 쿼리를 통해 SELECT Player Name,Pts FROM nhl ORDER BY Pts LIMIT 10

AWS 클라우드에 데이터베이스 서버와 API 마이크로서비스를 배포하세요. 프로젝트 1의 bash 셸 스크립트를 사용하여 AWS 인프라를 이미 만들었으므로 해당 스크립트를 재사용하고 편리한 경우 API와 데이터베이스를 배포하기 위해 적절하게 수정할 수 있습니다.

공용 인터넷에서 API에 액세스할 수 있는지 확인하십시오.

이 프로젝트에 사용된 모든 코드를 저장하기 위해 공개 GitHub 저장소를 만드세요.

GitHub 저장소의 README.md에서

API 및 데이터베이스 설정의 아키텍처 다이어그램을 포함하십시오.

사용 가능한 엔드포인트를 포함하여 사용자가 API 서비스를 사용할 수 있는 방법에 대한 지침을 포함합니다.

보너스:

API 마이크로서비스를 멋지게 만들고 싶다면 프론트엔드를 만들 수 있습니다. 사용자가 API 엔드포인트와 상호 작용할 수 있도록 Angular, React, Bootstrap 등. 그러나 이것은 필요하지 않습니다. 사용자는 웹 브라우저에서 URL로 엔드포인트를 입력하거나 Postman 또는 기타 API 클라이언트 등을 사용하여 엔드포인트를 칠 수 있습니다.

API 서비스에 고가용성과 확장성을 추가하려면 자동 확장 그룹의 일부인 EC2 인스턴스에 API를 배포하고 앞에 애플리케이션 로드 밸런서를 추가할 수 있습니다. 그런 다음 사용자는 애플리케이션 로드 밸런서 주소를 통해 API를 칠 것입니다.

참고: 데이터베이스에 사용할 수 있는 샘플 데이터 파일은 "연사 파일" 탭에서 찾을 수 있습니다. 그 파일의 이름은 "nhl-stats-2022.csv"입니다.
